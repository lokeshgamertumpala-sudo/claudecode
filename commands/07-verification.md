# Verification & Testing Engine

> Syntax validation, test execution, regression checks, and truth invariant testing.

| Command | Purpose & Usage |
| :--- | :--- |
| /verify/check | Run verification checks on code, tasks, or agent outputs. |
| /verify/start | Truth verification system for ensuring code quality and correctness with a 0.95 accuracy threshold. |
| /truth/start | View truth scores and reliability metrics for your codebase and agent tasks. |
