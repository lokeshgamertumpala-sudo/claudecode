# 🛡️ Apex Coder (/apex)

Operation / Target: $ARGUMENTS

Invoke the Apex Coder engine for zero-stub module generation, deep AST verification, or import crawling:

```cmd
python .agents/skills/apex-coder/scripts/apex_coder.py $ARGUMENTS
```

## Quick Commands:
- `/apex verify <path>`: Deep AST syntax and structure verification.
- `/apex generate --name <Name> --lang <python|typescript> --methods "<m1,m2>" [--out <file>]`: Synthesize a 100% complete zero-stub module.
- `/apex audit-imports [dir]`: Audit local import graph to guarantee zero orphaned modules.
