# 🚀 Claude Code Skills Master Suite (Code to Design)

This folder contains **20 production-grade skills** designed for Claude Code, covering the full product lifecycle from backend systems, clean architecture, and testing up to UI/UX design, Tailwind styling, micro-animations, and high-converting landing pages.

---

## ⚡ How to Use Skills in Claude Code

Skills can be used in **two powerful ways**:

### 1. Direct Slash Commands (`/<skill-name>`)
Type the skill name as a slash command directly in your Claude Code prompt:
```text
/code-refactor path/to/legacyModule.js
/tailwind-ninja Style a modern dark-mode card with glassmorphism
/bug-hunter Trace why this database query hangs after 30 seconds
```

### 2. Automatic Context Triggering
Claude Code automatically scans the skill descriptions in real-time. Whenever your natural language request matches a skill's purpose, Claude Code activates that skill and applies its expert instructions automatically!
- *Example*: Asking *"Make this hero section look like a world-class SaaS landing page"* will automatically activate `landing-page-hero`.

## 🛠️ Step-by-Step Workflow: From Code to Design

Here is how you can link these skills together for an end-to-end feature:

1. **Ideate & Wireframe**: Run `/ui-wireframe` to map layout and user flow.
2. **Design Tokens & System**: Run `/design-system` to establish typography, colors, and components.
3. **Build Frontend**: Run `/react-nextjs-pro` and `/tailwind-ninja` to build interactive components.
4. **Fluid Motion & Responsiveness**: Run `/micro-interactions` and `/responsive-wizard` for polish.
5. **Accessibility & UX Check**: Run `/ux-audit` and `/a11y-champion` for usability standards.
6. **Backend & Architecture**: Run `/api-architect` and `/database-architect` to connect APIs.
7. **Clean Code & Security**: Run `/code-refactor` and `/secure-code` to finalize the implementation.
8. **Automated Testing**: Run `/test-craftsman` to generate unit and integration tests.
