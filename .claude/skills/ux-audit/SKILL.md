# UX Audit Skill

This skill guides heuristic evaluations, user journey mapping, cognitive walkthroughs, and interaction friction audits to elevate user experience quality.

## Nielsen's 10 Usability Heuristics Checklist

1. **Visibility of System Status**:
   - Provide clear feedback within reasonable time (spinners, progress bars, toast messages, optimistic states).
2. **Match Between System and Real World**:
   - Speak the user's language with familiar concepts and terms; avoid technical jargon (e.g., "Payment could not be processed" instead of "Error code 0x800412").
3. **User Control and Freedom**:
   - Always provide easy undo, cancel, back buttons, and confirmation dialogs before destructive actions.
4. **Consistency and Standards**:
   - Maintain consistent wording, iconography, button colors, and interaction patterns across every screen.
5. **Error Prevention**:
   - Prevent errors before they happen (disable submit buttons during processing, inline validation, smart defaults).
6. **Recognition Over Recall**:
   - Keep options, actions, and previous inputs visible instead of forcing users to remember across multiple steps.
7. **Flexibility and Efficiency of Use**:
   - Provide keyboard shortcuts, recent searches, and accelerators for expert users without confusing novices.
8. **Aesthetic and Minimalist Design**:
   - Strip away non-essential information. Every additional piece of UI competes with relevant information.
9. **Recognize, Diagnose, and Recover from Errors**:
   - Express error messages in plain language, precisely indicate the problem, and suggest a constructive solution.
10. **Help and Documentation**:
    - Provide contextual tooltips, searchable help centers, and inline onboarding when needed.

## UX Friction Scoring Matrix

| Dimension | Questions to Evaluate | Rating (1-5) |
|---|---|---|
| **Clarity** | Can a first-time user understand what to do in < 5 seconds? | |
| **Cognitive Load** | Are there too many competing choices or visual noise? | |
| **Feedback** | Is every click/tap acknowledged with clear visual feedback? | |
| **Friction Points** | How many clicks/inputs does the primary flow require? | |
